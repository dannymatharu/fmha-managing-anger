Online learning for match officials

Everyofficialshapesthe game.

Referees are often the ones deciding, in the moment, whether a player's reaction is overload or dissent - and the wrong read can shape the rest of their game before anyone's had the chance to check. This course gives match officials a quick, practical way to get that read right.

Learn to recognise neurodivergent presentations in real time, respond without escalating, and know when to flag a pattern after the final whistle. Self-paced, 30-35 minutes, built for every grade on the panel - this is about recognition and response, not rule interpretation.

03 / Everyone on the pitch

This is for
more than one whistle.

Officials need a practical way to tell overload apart from dissent. Everyone else benefits from a game that stays calmer for it.

The proposed module welcomes officials of every grade - this isn't advanced CPD for the few, it's a baseline for the panel. No referee needs to be a specialist; they need a short, usable way to read what's in front of them and act on it.

10 / Common questions

Good to know.

Is this mandatory for all grades?

That's for each County FA to decide. The module is written to work for every grade from day one, so it can be phased in starting with grassroots or youth-qualified officials if that's preferred.

Does it replace existing referee CPD?

No. It sits alongside existing CPD rather than replacing any of it, and the optional live element piggybacks onto a CPD day you already run.

How long does it take?

30-35 minutes for the core module, built to be done in one sitting or paused and resumed.

Can officials revisit it?

Yes. Save-and-resume is built in, and there's no reason an official couldn't come back to it ahead of a new season.

Is there a live element?

An optional Q&A, run once on an existing CPD day - not a separate commitment in the diary.

Does it treat mini-soccer and 11-a-side the same way?

No - deliberately not. Cards aren't part of the Laws of Mini-Soccer (U7-U10), so the module's in-the-moment guidance for that age group is built around what a mini-soccer official can actually do: pause, a word with the coach, manage it directly. 11-a-side and above get the same framework, with the sanctions those grades actually have available to them.
